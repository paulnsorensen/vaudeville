# ADR pr-98-001: Hook output and project-rule trust decisions from the PR 98 review

- Status: accepted
- Date: 2026-09-23
- Context: PR 98 (typed rule core on pydantic-ai). Review report `.cheese/affinage/pr-98.md` (not tracked).

## Decisions

1. **A rewrite asks, it does not approve.**
   The Claude Code adapter renders a `rewrite` as `permissionDecision: "ask"` with `updatedInput`.
   Claude Code documents that `allow` bypasses the permission prompt regardless of permission settings.
   Project rules come from the repository, which spec F-7 treats as untrusted.
   A rewrite therefore changes tool input only. It never widens the user's permissions.

2. **One allow shape.**
   Every fail-open path returns `GENERIC_ALLOW`: empty stdout, exit code 0.
   The runner, the request handler, and the adapter use the same value.

3. **Project root is the git root.**
   The daemon resolves the project root from the hook `cwd` by walking up to the nearest `.git`.
   It falls back to `cwd` when no `.git` exists.
   Hook `cwd` follows `cd`, so a subdirectory session still loads `<root>/.vaudeville/rules`.
   The rule cache keeps at most 32 roots, keyed by the resolved real path.

4. **Project-layer rewrite scope.**
   A rewrite target may not name a leaf that runs code or routes I/O: `argv`, `command`, `commands`, `file_path`, `url`, `path`, `code`, `script`, `query`.
   The loader skips a project-layer rewrite rule whose matcher starts with `mcp__`.
   It also skips a project-layer rewrite rule with no matcher on `PreToolUse` or `PostToolUse`.
   A no-matcher rewrite on an event without tool input (for example `Stop`) stays, because it downgrades to feedback (AC-9).

5. **Rule references resolve at load.**
   `Action` requires `rule` for `rewrite` and `escalate`, and `command` for `run`.
   The loader drops a rule whose reference does not resolve to a rule of the right type, and logs a warning.

## Consequences

- A user approves each rewrite in the Claude Code permission prompt.
- The missing-key notice goes to the daemon log once per provider. Carrying it to the runner's stderr needs a protocol change (deferred).
